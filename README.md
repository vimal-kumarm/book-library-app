# book-library-app
A responsive Book Library web app to add, search, filter and manage your reading list — built with HTML, CSS &amp; JavaScript featuring star ratings, read/unread tracking and localStorage.
# 📚 Book Library App

A fully functional **Personal Book Library** web application built with
**HTML, CSS & JavaScript** — Day 7 Project of my Python Full Stack
Developer journey.

---

## 🚀 Live Demo
> Open `index.html` in your browser — no installation needed!

---

## ✨ Features

- ➕ **Add books** — title, author, genre
- 🗑️ **Delete books** — remove from library
- 🔍 **Search books** — filter by title or author instantly
- 🏷️ **Filter by status** — All / Read / Unread
- ✅ **Mark as Read / Unread** — track your reading progress
- ⭐ **Star Rating** — rate each book 1 to 5 stars
- 💾 **LocalStorage** — data saved after page refresh
- 📱 **Fully Responsive** — works on mobile and desktop

---

## 🛠️ Built With

| Technology | Purpose                              |
|------------|--------------------------------------|
| HTML5      | Page structure and layout            |
| CSS3       | Styling, responsive design           |
| JavaScript | Logic, DOM manipulation, localStorage|

---

## 🧠 JavaScript Concepts Used

| Concept             | Where Used                        |
|---------------------|-----------------------------------|
| Arrays + Objects    | Storing book list                 |
| `localStorage`      | Save books across page refresh    |
| DOM manipulation    | Add/remove/update book cards      |
| Event listeners     | Button clicks, input events       |
| `filter()`          | Search and filter books           |
| Template literals   | Build book card HTML              |
| `map()`             | Render all books                  |
| `find()`            | Get book by ID for rating/toggle  |
| Conditional logic   | Read/Unread, star rating display  |

---

## ⚙️ How to Run

\`\`\`bash
# Clone the repo
git clone https://github.com/YOUR_USERNAME/book-library-app.git

# Open folder
cd book-library-app

# Open in browser
# Double-click index.html OR use VS Code Live Server
\`\`\`

---

## 📸 How It Works

1. User fills in **book title, author, genre** and clicks Add
2. Book card appears with **star rating** and **Read/Unread toggle**
3. User can **search** by title or author in real time
4. User can **filter** to see only Read or Unread books
5. All data is **saved to localStorage** — persists after refresh
6. User can **delete** any book from the library
